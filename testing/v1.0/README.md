## What was v1.0?

The first production release of HelmLogic. Shipped the Stock Management
System, Quote Builder, Proposals, Dealer Fit, Promotions, Module framework,
and the initial Highfield + multi-vendor data-warehouse layout. 193 commits,
50+ new components, 8 new Firestore collections.

Start with [`overview.md`](./overview.md) if you're new to the product — it's
the shortest path to understanding the core feature set the later releases
build on.
