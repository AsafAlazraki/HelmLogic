# **App Name**: HelmLogic

## Core Features:

- Dashboard: Centralized view of key metrics and data visualizations related to maritime operations and logistics.
- Route Optimization: Generative AI powered feature that analyzes various factors (weather, traffic, vessel specs, regulations) to suggest optimal routes. The AI will use a tool to help decide when to incorporate some piece of information into its output.
- Real-Time Tracking: Monitor vessel locations and progress in real-time on an interactive map.
- Reporting: Generate reports based on your maritime activity.
- Highfield: A dummy page.

## Style Guidelines:

- Primary color: Blue (#0066CC), taken from the company logo, conveys trust and stability, reflecting maritime themes.
- Background color: Sea Mist (#C3F0F5), a lighter tint, provides a calming, neutral backdrop for content.
- Accent color: Blue Dark (#0053C2), adds depth and emphasizes key interactive elements.
- Grey: #808080 for less important UI elements.
- Yellow: #FFD700 for warnings.
- Body and headline font: 'Inter', a sans-serif font, is selected for its modern and clean aesthetic, which ensures readability and conveys a professional feel.
- Collapsible sidebar for navigation. It provides easy access to different sections of the app.
