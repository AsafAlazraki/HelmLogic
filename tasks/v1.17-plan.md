**Theme**: Turn the catalog from "edit one row at a time" into "edit thousands of rows efficiently", and drain the v1.11–v1.16 awaiting-repro bug backlog.

**Branch (when work starts)**: same dev branch — `claude/app-overview-wKiZ1`.

## Story slate (14 stories)

### A. Data-ops — catalog editing at scale (7 stories)
The natural next layer after v1.16's per-row polish. A salesperson + an org admin can now read and edit one trailer/motor/boat row at a time inline; v1.17 makes bulk operations possible without leaving the app.

- **3.10.1 — Multi-row select + bulk price adjustment**
  - Checkbox column on Motors / Trailers / Boats tables.
  - "Selected (N)" toolbar with: bulk markup % (Cost-driven sell recalc), bulk price-level retarget (e.g. flip 200 motors from Cash to Trade), bulk cost adjustment ±$.
  - Each row stays auditable — one `catalogAudit` event per row written.

- **3.10.2 — Paste-from-spreadsheet upload (CSV/TSV → preview diff → upsert)**
  - "Paste from spreadsheet" dialog. Operator pastes from Excel / Google Sheets, we parse the TSV in-browser.
  - Preview diff: side-by-side existing vs incoming for each row, key column auto-detected per the v1.4 upsert rule.
  - One-click apply with idempotent natural-key upsert (carry forward unchanged rows, mark created / updated / skipped in a toast).

- **3.10.3 — Cross-tab filter + search bar**
  - Single search box above the Catalog Manager tab strip that filters every tab simultaneously (Motors + Trailers + Boats + Fit-Up + Service Operations + Service Parts).
  - Type "highfield CL" → every tab narrows to Highfield CL rows.
  - Persists in URL like the existing Motors search.

- **3.11.3 — Per-vendor importer plug-in registry**
  - Standardise the v1.10/v1.11 Yamaha MPF importer + the v1.11 Sam Allen importer + the v1.4 trailer importer into a single registry pattern.
  - Each importer declares `{vendorId, columnMap, keyColumn, transformer}` — the Catalog Manager Import sheet picks the right importer from the active vendor row.
  - Unblocks new-vendor onboarding without touching the catalog component.

- **3.2.1 — Internal Data Normalisation Layer**
  - One source of truth for `cost / sellPriceExclGst / priceLevels / margin / inGstSell`. Today these are derived ad-hoc on every read site (proposal-pdf, motor cards, trailer dashboard).
  - New `src/lib/catalog/derivePricing.ts` returns the canonical shape; every read site switches to it.
  - Foundation for v1.18's quote variations + v1.19's margin-threshold enforcement.

- **3.9.4 — Trailer compat editor (boat ↔ trailer matrix)**
  - The dealer-fit compat editor (3.9.3) shipped in v1.16. Same pattern for trailers: per-model checklist of compatible trailer codes.
  - Powers the auto-filter on the Step 4 trailer picker (today it offers every trailer regardless of boat).

- **3.9.5 — Per-org vendor exchange rate editor**
  - Existing `organisations/{orgId}/exchangeRates/{currencyCode}` doc has rate + lastUpdated. Today it's set per-org via a one-off button.
  - New "Exchange Rates" card on `/manage` with full CRUD + history (audit-log on every change).
  - Plus a "rate stale" warning on motor/boat cards when the relevant rate is > 30 days old.
