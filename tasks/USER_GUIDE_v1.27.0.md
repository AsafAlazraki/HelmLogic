# v1.27 — User Guide

| Want to | Where |
|---|---|
| Attach documents to a customer | Customer record → documents |
| Offer a promotion to one customer only | Promotion setup |
| Keep your preferred list filters | Saved filter views |

**Customer documents**: files uploaded against a customer are stored under that customer's own Storage folder, so licences, ID, finance paperwork and signed docs live with the record they belong to.

**Customer-specific promotions**: a promotion can be left open to everyone, or restricted to named customers. When it's restricted, only those customers' quotes see it, which is how you handle a one-off negotiated deal without exposing it across the board.

**Saved filter views**: the filters you set on a list stick to your login, so you land back on the view you work in.

**Not in this release**: settlement reconciliation into Revolution is not built yet; it's waiting on Revolution system access. It stays on the roadmap as blocked, not done.
