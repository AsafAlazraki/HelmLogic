## Decisions Locked In (Don't Re-Litigate)

From the design doc review with the user:

1. **One module, many brands (Option A)** — not one module per brand
2. **New vendor type `Trailer Brand`** — alongside Boat Brand / Motor Brand / Internal
3. **Full price levels** — hull_cash, hull_trade, hull_subdealer, hull_subdealer_excl, hull_aus_sailing (same as motors)
4. **NO Promotions tab** — trailers don't get promotions (unlike Yamaha)
5. **Per-boat-model trailer assignments** — each boat model has its own `trailerAssignments[]` with pre-configured dealer fit (mirrors Motor Options pattern)
6. **Quote Step 4 reads assignments, not single trailerConfig** — default pre-selected, user can switch
7. **Dealer fit on Trailers module** — `trailerDealerFitCategories` on the Trailers module itself; `DealerFitOptions` merges four sources (global + boat module + motor module + trailer module)
8. **Excel import per brand** — same as MPF. Each brand has its own upload.
9. **One trailer per quote** — multiple trailers per quote is out of scope for v1.4
10. **Dashboard is the default catalog surface** (added 2026-04-22) — replaces the earlier "Catalog" tab. Tab URL param `?trailerTab=catalog` is remapped to `dashboard` for legacy bookmarks.
11. **Imports dedupe on natural key everywhere** (added 2026-04-22) — Yamaha MPF and Sam Allen were the two surfaces still doing clear-and-replace; both now upsert. `delivered-deals-import` and `stock-import` already dedupe.

## What's New vs the Original Design

The original design (§1–§12 of `v1.4-trailers-module-design.md`) is fully honoured. This continuation added four operator-ergonomics improvements on top:

1. **Dashboard visual language matching Yamaha** — gradient banner (orange instead of blue), aggregate stats, boat-size-range grouping (analogue of HP ranges), card + table view toggle with URL persistence.
2. **Admin CRUD on individual trailer docs** — image upload/paste-URL/remove + basic/specs/features/factory-options editor inline in the detail sheet. Pricing waterfall edits remain in the Pricing Manager tab.
3. **Module image editor** — reusable card for editing `modules/{id}.logoUrl`. Currently wired into the Trailers settings tab; drop-in for any other module workspace.
4. **Upsert imports** — any operator can now partial-import an xlsx without wiping rows that weren't in the file.

## Known Gotchas (Apply These From Day 1)

Pulled from `CLAUDE.md` — worth restating in the trailer context:

- **`priceLevels` object on every trailer row** — don't rely on `sellPriceExclGst` alone
- **`getPriceForLevel()` is the ONLY correct way to display price** — never hardcode `sellPriceExclGst` on cards, heroes, or grids. Regression that hit motors in v1.2.1 will hit trailers if we're not careful.
- **Inc GST `Math.ceil()` to whole dollars** per item row
- **Firestore `in` query capped at 30** — slice `trailerBrandVendorIds` if it ever exceeds 30 (unlikely but cheap insurance)
- **Loading overlay for TrailersWorkspace MUST be scoped to the active tab** — not a page-root overlay. v1.3.1's lesson applies.
- **URL-sync state** — `?trailerTab=`, `?trailerView=` sync to URL. Apply the same partial-param inference pattern as modules/[id]/page.tsx.
- **useMemoFirebase, not useMemo** — for any Firestore ref
- **`<img>` not `<Image>`** for external trailer CDN URLs
- **`optional().nullable().default()` + `.passthrough()`** on the Zod schema for trailer rows — legacy data will have missing/weird fields
- **Dashboard uses `getDocs` not `useCollection`** — aggregating multiple brand vendors dynamically via nested `useCollection` hooks is illegal (conditional hooks). The dashboard does flat `getDocs` per brand on mount + vendor-key change.
- **Imports are upsert by natural key** — Yamaha MPF, Sam Allen, delivered-deals, stock, trailer pricing. Operators who re-upload a partial xlsx will NOT wipe untouched rows. Toast reports `N updated · M created · K skipped (no key)`.
