# v1.26 — User Guide

| Want to | Where |
|---|---|
| Find any customer, quote or contract fast | Global Search (`/search`) |
| See where your customers come from | Customer source breakdown |
| Start a quote from a common build | Quote templates |
| Hide margin from non-authorised roles | Role permissions |
| Track what a customer still owes | Outstanding balance |
| Read a quote's change history | Variation history |
| Catch promotions before they lapse | Promotion alerts |

**Global Search**: open the Search page and type. Results are grouped by type (customers, quotes, contracts); click a row to jump straight into that record. This is the fastest way to reach anything when you know a name or number.

**Margin visibility**: margin only shows for roles that have been granted `can_view_margin` (or margin override) in Manage → Roles. If a salesperson can't see margin, that's by design; an admin can grant the permission.

**Everything else this release** — source tracking, quote templates, outstanding balance, variation history and promotion alerts — is foundation this cycle; the numbers and lists are computed and correct, and their dedicated on-screen surfaces get their polish during UAT.
