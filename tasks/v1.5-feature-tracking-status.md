## Known Gotchas (for testers and future-me)

- **Drag vs click live on the same surface.** Drag activation requires 5px of pointer movement (PointerSensor `distance:5`). A plain click opens the detail sheet. The vote button stops propagation so clicking it doesn't open the sheet.
- **Fractional index math is exact but not infinite.** After ~50 adjacent inserts in the same slot the midpoints shrink into float-precision rounding. We aren't close to that in practice; if it becomes real, renumber the column to integer multiples on next drop.
- **Sort mode isn't persisted.** Per-column sort is session-local state in the board. Refreshing the page resets everything to 'manual'. If testers want persistence we'll push it into `localStorage` keyed by column.
- **Drag is disabled in non-manual sort modes.** Expected behaviour — we won't let drops silently stomp `order` while the card position is being driven by votes or date. Cursor turns from grab → pointer, title tooltip says "Click to open".
- **`commentCount` is a denorm.** Card badge reads `feature.commentCount`, not the subcollection size. `postComment` calls `increment(1)`, `removeComment` calls `increment(-1)`. If a write fails mid-flight the count could drift; if that ever happens, a cloud function or a manual re-count tool is the fix.
- **Images upload to `features/{featureId}/` BEFORE the feature doc exists.** The create dialog generates the feature ID client-side via `doc(collection(firestore, 'features')).id` so the uploader has a path to write to. If the user cancels the dialog after uploading, the Storage objects stay. Not a security issue (bucket is still gated by rules) but worth cleaning up if storage cost becomes a concern.
- **Everyone can delete everything.** Per spec. If this gets abused we bolt on an ownership guard in the rules + a soft-delete flag before anything else.
- **Title validation is 3 chars min.** Submit button stays disabled until the title clears 3 chars. Description, tags, acceptance criteria, images, target release are all optional.
- **Cmd/Ctrl + Enter posts a comment.** The submit button is there for mouse users. Comment box is a plain `<textarea>`, not TipTap — keep comments short.

## Tester Cases

### Create
1. From Submitted column (empty), click New Feature. Fill in title only (≥3 chars). Submit. Card should appear at top of Submitted.
2. Create a feature with full metadata: description with H2 + H3 + bullets + a link, 2 acceptance criteria, 3 tags, target release "v1.6", 2 uploaded images + 1 pasted URL.
3. Submit with only 2 chars in title → Submit button disabled.
4. Submit without being signed in → toast "Not signed in".

### Vote
5. On a card, click the ThumbsUp → button flips filled, count increments. Click again → count decrements.
6. Vote on the same card from a second browser/account → count goes to 2.

### Drag
7. Drag a card within Submitted, drop between two neighbours → position and order update, persists on refresh.
8. Drag a card from Submitted to Planned → column and status persist on refresh.
9. Drop a card on an empty column body → appends at end of that column.
10. Drag a card and drop it where it started → no-op, no Firestore write.
11. Two tabs open: drag a card in tab A → tab B reflects the move within ~500ms.

### Sort
12. Switch a column to "Most votes" → cards reorder by vote count. Drag cursor becomes pointer, drag is disabled.
13. Switch to "Newest first" → reorder by createdAt DESC.
14. Switch back to "Manual" → order matches the last drag state.

### Detail sheet
15. Click a card → sheet opens on the right.
16. Change status from Submitted to In Progress via the Status select → card moves column on the board behind the sheet.
17. Change Type and Priority → updates persist on close/reopen.
18. Edit description: click Edit → TipTap editor. Make changes → Save button enabled. Save → read-only view shows new content.
19. Cancel description edit → reverts to previous content.
20. Add a tag → chip appears. Click chip's X → chip removed.
21. Add an acceptance criterion → bullet appears with a green checkmark.
22. Change target release to empty string → stored as null (not "").
23. Upload an image in the sheet → appears in the grid. Remove it → grid updates.
24. Post a comment → appears below, card's comment count increments. Cmd/Ctrl+Enter also posts.
25. Delete a comment → count decrements.
26. Click Delete on the feature → confirm dialog, then the card disappears from the board, sheet closes.

### Edge
27. Feature with no description → detail sheet shows "No description." italic.
28. Feature with 0 votes → card shows "0" next to ThumbsUp.
29. Feature with 10 images → uploader shows "Max reached".
30. Open a feature on one tab, delete it from another tab → sheet closes cleanly (feature becomes null via snapshot).
