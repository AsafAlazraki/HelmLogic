# v1.21 — Plan (Customer CRM foundation)

**Theme**: Stand up the customer record as a first-class entity. Detail sheet, cross-module quotes view, reporting dashboard, plus the lifecycle bits that hang off a customer (acceptance capture, trade-in, inventory allocation, pending units).

**Status**: Planning. No code written yet.
**Branch**: dev — `claude/app-overview-wKiZ1`.
**Workflow**: every surface gets a browser walkthrough that runs against the dev URL. Report green before moving on.

---

## Story slate (8 shippable + 3 NSM-Hub blocked)

### Phase A — Customer CRM core (3 stories)

- **8.1.2 Customer Detail Sheet**
  - One sheet that shows everything about a customer: contact details, lifecycle stage, source, primary/secondary buyer, trade-in, linked quotes + contracts, notes count.
  - Reads the v1.12/3.4.1 `customers/{id}` schema (already shipped) + cross-references quotes.
  - New `src/components/customer-detail-sheet.tsx`.

- **8.1.4 Cross-module Quotes view (sort + filter)**
  - A flat list of every quote across modules with sort (date / value / status) + filter (status / lifecycle / salesperson).
  - New page surface; reads `users/{uid}/quotes` collection-group.

- **8.2.1 Reporting & Analytics Dashboard**
  - At-a-glance metrics: quotes this month, conversion rate, total pipeline value, deposits taken, margin distribution.
  - New `src/components/reporting-dashboard.tsx` + page.

### Phase B — Lifecycle bits (4 stories)

- **1.4.3 Acceptance Capture** — record when a customer accepts a quote (date, method, who). Schema + proposal-view action.
- **1.5.5 Trade-In Record** — structured trade-in capture (make/model/year/value/payout) on the customer + quote.
- **2.5.3 Inventory Allocation to Contract** — link a stock item to a contract so it's marked allocated.
- **Pending Units** + **Date of creation or date of order** — stock-status surfacing on the module dashboard.

### Conditional track — NSM-Hub (3 stories, blocked)

- **11.3.1 / 11.3.2 / 11.3.3** — still service-account-blocked. Will NOT fake-ship. Carries to v1.22 if still blocked.
