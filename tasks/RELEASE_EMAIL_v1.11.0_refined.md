A few things to pre-empt up front:

## Why are there no Yamaha outboard images on the PDF?

Right now those images are SharePoint links that HL renders live in the browser. That works in the app, but a server-rendered PDF can't follow the link (SharePoint blocks the fetch), so the image slot falls back to the placeholder.

**This is already fixable today** — v1.11 ships an **Upload Photo / Replace** button on every motor row in the catalog (Manage → Motors → click a row). When you upload, the image lands in Firebase Storage and renders on the PDF correctly. We just need to do the data entry — about 5 minutes per motor, manual.

My recommendation is to schedule this alongside the Shopify migration so we're not double-handling. If we need a few motors done now for sales-floor demos, happy to walk through it on a call.

## Why are there no trailer images on the PDF?

Same story — trailer catalog rows have a paste-the-URL field plus an **Upload / Replace** button (Manage → Trailers → click a row → Image editor). Upload once and it's permanent across every quote.

## How do we fix the images properly long-term?

Migrate the SharePoint URLs to uploaded images. Lengthy but linear. Recommendation stands: do this as part of the Shopify activities so we cut over once.

## A note on the dynamic content blocks

Currently every dynamically created section (cover letter, terms, custom blocks) gets its own page — easier to control formatting that way. If we'd prefer tighter dynamic overflow (multiple short blocks on one page), happy to make that change. Tell me which way you want it and I'll line it up.

## What's actually in this release

There's far more shipped than I can fit in an email — please head to **HL → Release Notes** and **Feature Tracking → How to use** for the full breakdown. Headlines:

- **Fit-Up & Rigging** as a first-class section on Step 5 — Simple / Medium / Complex tier package cards on every quote, plus the per-line workshop controls (quantity, price override, notes)
- **Workshop status pill** on every proposal — tracks the build independently of the sales lifecycle
- **Sharper customer PDF** — nested Investment Summary that reads like a real itemised quote, trailer image restored (when uploaded), 5-band "Your Build" stack
- **Catalog Manager** (was Pricing Manager) — Catalog xlsx export/import with diff-preview before commit, unified Catalog Audit feed showing every change
- **Audit trail** — every proposal has an Activity tab logging who did what when (created · sent · locked · discount changed · etc.) and the Catalog Audit answers the same on the catalog side
- **Customer Defaults + Document Defaults** cards — edit the customer source dropdown, pipeline stages, deposit %, payment schedule template once at org level instead of every quote
- **Mark's 8-item checklist proven end-to-end** on Classic CL380 + Sport SP600 — both PDFs (one attached) generated by automated tests so we'd catch any regression instantly
