# v1.28 — User Guide

| Want to | Where |
|---|---|
| Record a spouse / co-buyer on a deal | Customer / quote buyer fields |
| Process a refund on a cancellation | Contract → refund |
| Combine more than one promotion | Promotion setup → stacking |

**Co-buyers**: a deal can name a primary and a secondary buyer. Where both are present the deal shows as "Name & Name", which is what you want on a jointly-owned boat.

**Refunds**: a refund is recorded against the contract with a reason and who processed it, and it nets down the paid-to-date figure so the balance reflects reality after a cancellation or overpayment.

**Promotion stacking**: by default a quote takes the single best promotion available. If stacking is allowed, promotions apply best-first (up to the stack limit), each one discounting what's left rather than the original price, so the combined discount stays sensible.
