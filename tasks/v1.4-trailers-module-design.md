# v1.4 Trailers Module — Design Document

> Status: Design phase (this week) — implementation in v1.4 next week
> Decisions baked in: Multi-brand single module (Option A), Excel import, full price levels, no promotions, model.trailerConfig sourced from Trailers module, dealer fit support like Yamaha

---

## 1. Overview

A new module type `trailers` that:
- Aggregates multiple trailer brands (e.g., Mackay, Dunbier, Easytow, Jurgens) under one module
- Becomes an **associated vendor** to boat modules (Highfield) so trailer pricing flows through to boat quotes
- Has its own dealer fit categories (Spare Wheel, Hold Down Straps, Registration, etc.)
- Mirrors the Yamaha workspace UX (Catalog, Pricing Manager, Settings) — minus Promotions

## 2. Module Type

### New value
- `moduleType: 'trailers'`

### Module document fields
```
modules/{trailerModuleId}:
  moduleType: 'trailers'
  name: 'Trailers'
  mainVendorId: null                       ← no single main vendor
  trailerBrandVendorIds: string[]           ← NEW — array of trailer brand vendor IDs
  moduleDealerFitCategories: string[]       ← reused — trailer dealer fit categories
  associatedVendorIds: string[]             ← MPF/parts vendors for dealer fit items
  brandCaptainUserId, moduleManagerUserId   ← role assignments
  coverImageUrl: string                     ← module card image (a generic trailers icon)
  stockLocations: string[]                  ← if trailers tracked in stock
```

## 3. Vendors

Each trailer brand is its own vendor in `data-warehouse/{vendorId}`:

```
data-warehouse/{trailerVendorId}:
  name: 'Mackay Trailers'
  vendorType: 'Trailer Brand'             ← NEW vendor type
  logoUrl: '...'
  currency: 'AUD'

```

### Vendor type values (current + new)
- `Boat Brand` (Highfield, Stabicraft, etc.)
- `Motor Brand` (Yamaha)
- `Trailer Brand` ← **NEW**
- `Internal` (Master Price File)

## 4. Data Import (Excel)

Each trailer brand has its own Excel file (or sheet). Import flow mirrors MPF:

- User clicks "Import Excel File" in the Trailers workspace Settings
- Selects the brand the data belongs to
- Uploads Excel — each row becomes a doc in `data-warehouse/{trailerVendorId}/dataSets/{name}/rows/{id}`
- Brand association is implicit (vendor = brand)

### Expected Excel columns (per brand — flexible)
- **Required**: Model, Length, Weight (Tare), Capacity (ATM)
- **Pricing**: Cost, NSM Retail / Cash Price, Trade Price, Sub-Dealer Price, Sub-Dealer Excl Price, AUS Sailing Price (matching Yamaha column structure)
- **Specs**: Axles, Suspension, Brakes, Tyres, Drawbar, Hub Type, Lights
- **Optional**: Image URL, Notes, Compliance details

Same flexible field-name handling as Yamaha — `getMotorName`-style helpers that try multiple casings.

### Row document structure
```
data-warehouse/{trailerVendorId}/dataSets/{datasetId}/rows/{rowId}:
  Model: 'Mackay 4.5m Single Axle Braked'
  Length: 4.5
  Weight: 250
  Capacity: 750
  Cash Price: 3500
  Trade Price: 3200
  ...
  // Built at fetch time:
  priceLevels: {
    hull_cash: 3500,
    hull_trade: 3200,
    hull_subdealer: 3200,
    hull_subdealer_excl: 3200,
    hull_aus_sailing: 3200,
  }
  sellPriceExclGst: 3500    ← primary, defaults to hull_cash
  costPrice: 2400           ← from Cost column
  brandVendorId: '<vendorId>'   ← injected at fetch for grouping
  brandName: 'Mackay Trailers'  ← injected at fetch for badges
```

## 5. Workspace UI — TrailersWorkspace

New component: `src/components/trailers-workspace.tsx`

Modeled directly on `YamahaMotorWorkspace` with these tab differences:

### Tabs
- **Catalog** (default)
- **Pricing Manager**
- **Settings**
- ❌ NO Promotions tab (per user)

### Catalog Tab

**Header**:
- Search bar (filters across all brands)
- Brand selector dropdown: "All Brands" / "Mackay" / "Dunbier" / etc.
- Sort: Length / Weight / Price / Name

**Grid**:
- Trailer cards grouped by brand (when "All Brands" selected) OR flat grid (when single brand selected)
- Each card shows:
  - Trailer image (or Truck icon placeholder)
  - **Brand badge** (top-left, brand-coloured)
  - Model name
  - Length + Capacity badges
  - Price (at current price level)
  - Click → opens Trailer Detail Sheet

### Trailer Detail Sheet (side panel ~480px, like Motor Detail)
- Hero image
- Brand logo + name
- Quick stats: Length, Weight, Capacity, Price
- Specifications grid (all spec fields)
- **Dealer Fit Options** section at bottom — same Master Data Browser as Yamaha (uses `moduleOnly` so only shows the Trailers module's own DF categories)

### Pricing Manager Tab

**Sub-tabs per brand**: Mackay / Dunbier / Easytow
- Each sub-tab renders `MasterPriceFileWorkspace` scoped to that brand's vendor
- Same editable cell UX, Excel import, GST-aware pricing
- Inc GST values rounded to whole dollars (inherited from v1.2.1)

### Settings Tab

- **Trailer Brands**: Add/remove trailer brand vendors (writes to `trailerBrandVendorIds`)
- **Associated Vendors**: MPF vendors for dealer fit data
- **Dealer Fit Categories**: `ModuleDealerFitManager` with `fieldName="moduleDealerFitCategories"`, title "Trailer Dealer Fit Categories" (e.g., Spare Wheel, Hold Down Straps, Registration, Lock, Wheel Brace)
- **Module Roles**: Brand Captain, Module Manager

## 6. Quote Builder Integration (Step 4)

This is where it gets clever. Boat modules (Highfield) reference the Trailers module for trailer pricing.

### Boat module setup
- Add the Trailers module's `trailerBrandVendorIds` to the Highfield module's `associatedVendorIds`
  - OR introduce a new field `trailersModuleId` on boat modules pointing at the Trailers module

### Quote flow Step 4 changes

**Current behaviour**: Step 4 shows `model.trailerConfig` (a single trailer attached to the boat model). User can select it or skip.

**New behaviour**:
1. Step 4 still shows `model.trailerConfig` as the "recommended" trailer
2. Trailer pricing for that recommended trailer comes from the **Trailers module data** (matched by trailerId or model name)
3. **NEW**: A "Choose Another Trailer" button below the trailer card → opens trailer browser
4. Trailer browser is a Sheet/Dialog showing the full Trailers module catalog with brand filter
5. User picks a trailer → it replaces the recommended one in the quote
6. Trailer factory options (existing v1.3 feature) still work
7. Trailer dealer fit pulls from the **Trailers module's** `moduleDealerFitCategories`

### Pricing resolution
- Trailer `priceLevels` flows through `getPriceForLevel` (same as motors)
- Sub-dealers automatically get Trade pricing on trailers
- Hero card price changes when price level selector changes (same fix as motors v1.2.1)

### Snapshot at finalize
```
users/{uid}/quotes/{qid}.trailer:
  brandVendorId: 'mackay-vendor-id'
  brandName: 'Mackay Trailers'
  trailerId: 'rowId'
  name: 'Mackay 4.5m Single Axle Braked'
  sellPriceExclGst: 3200    ← resolved at the selected price level
  costPrice: 2400
  imageUrl: '...'
  options: [...]            ← existing trailer options
  customOptions: [...]      ← existing custom trailer notes
  // Specs snapshotted for proposal/PDF
  length: 4.5
  capacity: 750
  axles: 1
```

## 7. Dealer Fit — Where Categories Live

### Current state (v1.3)
- Boat module has `trailerDealerFitCategories[]` (added in v1.3)
- Quote flow Step 4 reads from boat module's field

### New state (v1.4)
- Trailers module has its OWN `moduleDealerFitCategories[]` (the standard field)
- Quote flow Step 4 reads from the **Trailers module** if the boat module is associated to a Trailers module
- Falls back to boat module's `trailerDealerFitCategories` if no Trailers module is linked
- This lets each org configure trailer DF categories ONCE on the Trailers module rather than per boat module

### Migration
- Existing `trailerDealerFitCategories` on boat modules can be migrated to the new Trailers module's `moduleDealerFitCategories` when the Trailers module is created
- Or kept as a per-boat-module override

## 8. Pricing Workspace (Same as Boat Pricing)

Each trailer brand gets the full v1.2.1 pricing treatment:
- Cost + freight + handling + pre-delivery → landed cost
- Margin → sell ex GST
- All price levels (hull_cash, hull_trade, hull_subdealer, hull_subdealer_excl, hull_aus_sailing)
- Inc GST rounded UP to whole dollars
- Publish writes `priceLevels` object to each trailer row

This works because we reuse `MasterPriceFileWorkspace` per brand sub-tab.
