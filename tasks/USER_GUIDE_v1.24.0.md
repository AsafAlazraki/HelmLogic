# v1.24 — User Guide

| Want to | Where |
|---|---|
| Log a note on a customer | Customer detail sheet → Notes |
| See where a customer is in the journey | Customer detail sheet → journey strip |
| Track a factory order | Contract detail sheet → Factory order |

**Notes**: type and send; they timeline newest-first with who + when.
**Journey**: a visual strip showing the customer's lifecycle position.
**Order tracking**: progress bar from Ordered through to Delivered.
