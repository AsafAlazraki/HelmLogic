# v1.22 — User Guide

**Audience**: org admins + salespeople.

| Want to | Where |
|---|---|
| Find customers / contracts / reporting | Sales nav group |
| See all contracts | Sales → Contracts |
| Set the margin floor | Settings → Margin threshold card |
| See recent activity | Reporting page |

**Sales workspace**: the sidebar now has a Sales group. Everything customer-facing lives there.
**Contracts**: filter by state, sort by newest/value/state.
**Margin threshold**: set the % below which a quote needs a GM override to finalize. Default 15%.
**Activity feed**: recent quote/contract events across the org, on the Reporting page.

## NOT in v1.22
RBAC isolation (v2.1), NSM-Hub (blocked).
