# v1.23 — User Guide

| Want to | Where |
|---|---|
| See the sales pipeline | Sales → Pipeline |
| See a contract's payment schedule | Contract detail sheet |
| See just my work | Sales → My Work |

**Pipeline**: customers laid out by stage (Lead → Delivered). At-a-glance board.
**Payment schedule**: deposit + milestones + balance on delivery, with paid/due totals.
**My Work**: your quotes, customers, and contracts in one place.
